# Intellectual Property Boundary

This repository is a **public portfolio demonstration** built independently from a separate private research/evidence repository.

## What is intentionally not included

- Private source code
- Original operational datasets
- Site, station, customer, or device identifiers
- Private model weights or artifacts
- Tuned production parameters
- Patent-related implementation details
- Git history from the private repository

The examples here use generated synthetic data and a deliberately simplified baseline implementation.

No open-source license is intentionally provided for this repository at this time. Publication on GitHub does not grant rights to any separate private implementation, patent, dataset, model, or other confidential material.
